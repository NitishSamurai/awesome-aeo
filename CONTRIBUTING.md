# Contributing to Awesome AEO

Thanks for helping keep this list useful! A few guidelines so we can merge your PR quickly.

## What belongs here

Resources genuinely useful for **Answer Engine Optimization (AEO)** / **Generative Engine Optimization (GEO)**:

- Tools that track or improve AI-search visibility
- Free utilities (generators, checkers, validators)
- High-quality guides and playbooks
- Standards, specs, and official documentation
- Research, papers, and source-linked data studies

## How to add an entry

1. Fork this repo and edit `README.md`.
2. Add your entry to the most relevant section, in this format:
   ```markdown
   - [Name](https://example.com) — One-line, neutral description (what it does).
   ```
3. Keep descriptions factual — no marketing superlatives ("best", "#1", "revolutionary").
4. Make sure the link works and points to a real, live page.
5. Open a pull request with a short note on why it belongs.

## What we'll reject

- Dead or redirecting links
- Pure marketing pages with no substance
- Duplicate entries
- Hype-filled descriptions

## Removing entries

If a tool shuts down or a link dies, please open a PR removing it. Keeping the list accurate matters more than keeping it long.
